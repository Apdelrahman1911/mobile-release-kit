## Nonshipping backup boundary

The only destination exemption is the already existing
`BackupDestinations::new_component_fixture`, in test/debug Mac source. The new
fixed installed Document adapter chooses only `backup` and `recovery` siblings
under its genuine Control namespace. It never calls a public path setter,
manufactures `SelectedPair`/`GuiFacts`, or changes production `choose_backup`,
pickers, encrypted-vault permission gates or native qualification constants.
Both destination parents are created/held once by the original `Fixtures`.

`ComponentPair` is a non-Clone native-only **comparison handoff**, not a read or
write receipt. It is captured from the SAME completed destination originals
inside the existing successful BackupDelivered validation, after its unchanged
native/child/coordinator/currentness checks and before private drain. It retains
the actual final parent identities, post-rename file identities and bounded
actual paths; neither a report nor a guessed export ID can construct it.
It exposes no file contents, recovery code, key/password or serde projection.

Only after real publication **and returned private drain** may ordinary source
Lock occur. The later import moves that handoff once into the existing source
owner. At the actual held/named source PRE, both complete expected parent/file
witnesses are compared **before private body allocation**. Original APFS,
no-follow, ownership/ACL, bounds, EOF, POST and close checks remain in force.
Full backup authentication is still required; filenames/metadata do not prove
key equivalence. The same NEW save then authenticates the complete readback
against its retained restored payload before publishing StoredNew.

The target is only the precreated `restored` sibling's previously absent fixed
application/vault. It must open uninitialized and really initialize; no old
vault/header is adopted or replaced. The new vault/generation/record/random
revision differ from the generated source. The subsequent actual Load/Assess
and explicit Bind use only the fresh reference/current context; source
assignments, journal privileges and generation consent are not restored.

The comparison paths are reserved at their actual 4096-byte-per-path maximum
in the existing same-Document census before export. Private sink/source/crypto
buffers and their actual capacities keep the original accounting. A failed
borrow, unavailable census, uncertain write/read/close/join or lost publication
never permits another export, import, new code, deletion or NEW attempt.

## Outer return, readback and retention

The existing source-bound namespace remains exclusive to this case/caller.
The added fixed sibling parents and their original FDs remain in `Fixtures`;
all native application/vault/file leaves are created by their real owners.
After CompletedProcess0 plus the exact positive report, the Python leaf checks
only the finite metadata roster (source vault/Host, two corresponding private
backup files, fresh target vault). It does not read private contents, parse a
password/code, authenticate ciphertext or import report-supplied paths.

The original current-runtime POST and every fixture close must return before
`macos-upload-key-backup-current-complete`. Unknown/nonzero/foreign/missing
output cannot complete. Exit78 is only the unchanged, fully parsed and joined
before-generation missing-prerequisite path, with no backup/target output; it
is not a native error, skip-to-next attempt or positive qualification.

No synthetic key, vault, backup/code or Keychain row is deleted by this journey.
They remain in the isolated disposable hosted account until its normal
retirement, including failures. A lost close retains original custody and
diagnostics, not a claimed safe cleanup. No ambient user's keys are used.
The public report says backend-without-pickers, saved/loaded/bound and the real
known dispositions; it contains no private bytes/paths/references and explicitly
denies picker/physical-Mac, cold restart, release signing and automatic Bind.
This does **not** combine A's two-process test with B, test a crash, or prove
jarsigner/Play/release usability.
