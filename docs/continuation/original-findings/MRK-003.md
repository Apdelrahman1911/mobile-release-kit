### MRK-003 — High — Latest run attempt rejects valid earlier-attempt evidence

- **Affected:** `.github/workflows/reusable-external-testing.yml:121-164,345-388`; `.github/workflows/reusable-production-submit.yml:134-207,395-469`.
- **Trigger:** In a `both` run, one platform succeeds on attempt 1 and another succeeds after “rerun failed jobs” on attempt 2.
- **Expected:** Each attested artifact should be checked against the attempt that produced it.
- **Actual:** Evidence records attempt 1, while GitHub’s run endpoint reports the latest attempt 2; equality checks reject the valid attempt-1 artifact.
- **Evidence:** The isolated predicate reproduction returned false and exit status 1.
- **Impact:** Legitimate Android or iOS evidence becomes unusable for external testing or production.
- **Cause:** Run-level latest-attempt metadata is treated as artifact provenance.
- **Correction:** Query the attempt-specific endpoint or validate artifact/job provenance for the recorded attempt while separately requiring the overall run to succeed.
- **Verification:** Exercise all mixed attempt-1/attempt-2 Android/iOS combinations.
- **Blocks:** Toolkit release and multi-platform promotion/production reruns.
