### MRK-006 — Medium — `init --apply` is not transactional

- **Affected:** `src/mobile_release/cli.py:315-397`.
- **Trigger:** A later workflow, metadata, or `.gitignore` write fails after earlier writes succeed.
- **Expected:** Either all generated files are installed or the original tree is restored.
- **Actual:** Earlier files remain. A forced workflow-write failure left the configuration file but no workflow.
- **Impact:** Consumers receive a partially initialized, difficult-to-retry integration.
- **Correction:** Stage all content and atomically commit it, or maintain backups and roll back every completed write.
- **Verification:** Inject failure at every write position, including `--force` over existing files.
- **Blocks:** Reliable consumer integration.
