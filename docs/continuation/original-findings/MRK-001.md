### MRK-001 — High — Play operations replace destination release lists

- **Affected:** `fastlane/Fastfile:179-223,385-413,457-525`; locked Fastlane `supply/lib/supply/uploader.rb:187-233,422-458`.
- **Trigger:** Uploading or promoting when the destination track already contains other releases.
- **Expected:** Add the intended release while preserving unrelated completed, staged, halted, or draft releases.
- **Actual:** Supply assigns `track.releases = [release]` or `[track_release]` before updating the track.
- **Impact:** Existing testing releases or the currently serving production release can be removed or altered. A production draft may replace the destination’s release list.
- **Cause:** The toolkit relies on Supply’s singleton track-update behavior without merging and verifying the existing track state.
- **Correction:** Read the complete destination track, merge only the intended release, preserve every unrelated release, commit, and compare full before/after state.
- **Verification:** Test populated tracks containing completed, staged, halted, and draft releases; perform a controlled non-production API rehearsal.
- **Blocks:** Toolkit release and all Android candidate, promotion, and production paths.
