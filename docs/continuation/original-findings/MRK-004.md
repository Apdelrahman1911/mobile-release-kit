### MRK-004 — Medium — Android release notes are optional

- **Affected:** `src/mobile_release/metadata.py:20-42,159-253`; `src/mobile_release/cli.py:252-281`; `fastlane/Fastfile:205-223,493-511`; Supply uploader `236-263`.
- **Trigger:** Configured Android locale contains listing text but no version-specific or default changelog.
- **Expected:** Production preparation fails before Store mutation.
- **Actual:** Validation passes; Supply creates an empty localized changelog.
- **Impact:** Empty “What’s new” text can reach production metadata.
- **Correction:** Require a non-empty `changelogs/<versionCode>.txt` or `changelogs/default.txt` per locale and generate it in the init skeleton.
- **Verification:** Add absent, empty, placeholder, oversized, and fallback tests.
- **Blocks:** Android production preparation.
