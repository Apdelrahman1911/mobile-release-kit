## Real path and use

1. Enable ordinary project READ access and select that project's existing
   Android/iOS locale in Desktop's metadata editor. Keep unrelated drafts safe.
2. `mrk metadata-text-read PROJECT_ID OBSERVATION_REVISION android|ios LOCALE --json`
   creates its request ID before send. The retained controller invokes the
   original passive MetadataTextObserve command. Actual Supervisor retirement
   **and** the original bridge caller return precede public Loaded text.
3. `mrk metadata-text-prepare PROJECT_ID SERVICE_INSTANCE REQUEST_ID --stdin --json`
   accepts `{"platform":"android|ios","fields":[{"id":"…","text":"…"},…]}`.
   Supply all three Android or five iOS fields in their existing core order;
   there are no caller paths, roots, baseline witnesses, partial merges or
   translation. The genuine new native Open must match every retained Load
   baseline/config hash and metadata root before Prepare. Drift refuses; it
   never reloads or silently rebases the proposal.
4. Desktop shows the original native full before/after preview. Its collapsed
   Advanced controls require separate unchecked one-use consent
   `agent-exact-metadata-text-preview-v1`. Neither READ nor `--reviewed` grants it.
5. `mrk metadata-text-apply PROJECT_ID SERVICE_INSTANCE REQUEST_ID SESSION_ID OWNER_GENERATION REVISION PLAN_TOKEN --reviewed --json`
   queues only the exact consented original. The same retained controller invokes
   the existing native Apply. It preserves the native writer, conditional source
   checks, original clocks, seven publication transitions, cancellation, final
   source/EOF/close/retirement and actual original command Promise.
6. `metadata-text-status` / `metadata-text-cancel` take only
   `PROJECT_ID SERVICE_INSTANCE REQUEST_ID [--json]`. Missing ACKs retain that ID
   and never replay Load, Prepare or Apply. Ordinary `mrk requests` discovers the
   correct MetadataText family in the same Configuration32 namespace.

Only the active Loaded row returns public text. Terminal rows retain bounded
IDs/digest/outcome, not descriptions. A cancelled committed write is not reported
as a normal saved success; unknown cleanup is absorbing. A later queued row
cannot erase the prior final: explicit Check queries the exact retained ID.
Desktop draft/baseline objects are never adopted or cleared by this route;
Apply uses the existing stale-boundary invalidation. Native caller proof, not
renderer status/elapsed time, decides settlement.
