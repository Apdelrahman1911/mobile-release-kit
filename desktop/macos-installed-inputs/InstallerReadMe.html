Engineering fresh installation only

This package supports the fixed macOS 26 ARM64 profile. Installer obtains administrator authorization; only the fixed native installer writes the app and runtime. The application and Python never run as root.

The app belongs at /Library/Application Support/MobileReleaseKit/Mobile Release Kit.app. This is not a movable drag-copy installation. No other location is offered or searched.

Update, repair, restore, same-package reinstall and uninstall are unavailable in this engineering package. An occupied app or runtime is refused, not replaced. A Distribution wrapper does not change those rules. The existing engineering-v1 installation has no automatic migration route.

Quit Mobile Release Kit and finish its work before continuing. Installer's quit prompt does not prove that all original workers have settled or provide a maintenance live-use gate.

Keep projects, credential vault and Keychain records, signing originals, provider registrations, moved copies, unrelated files and partial-installation evidence. Do not delete the protected tree, change its permissions, or force-close processes to make a retry pass.

For a missing, moved or conflicting installation, preserve the existing files and obtain a separately reviewed recovery route. This package does not search for, move or remove another copy.
